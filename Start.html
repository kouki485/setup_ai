AI 開発環境セットアップ

このページはブラウザで開いています。ここからなら macOS の警告で止まりません。

Mac で Start_Mac.command をダブルクリックすると止まるでエラーになります。
Apple のセキュリティ（Gatekeeper）の仕様です。下の方法で進めてください。

おすすめ: ターミナルに 1 行貼り付け

ZIP を使わず、Homebrew と同じ入れ方です。Gatekeeper の警告は出ません。

  1. Launchpad →「その他」→「ターミナル」を開く
  2. 下の「コマンドをコピー」を押す
  3. ターミナルに貼り付けて Enter
curl -fsSL https://raw.githubusercontent.com/kouki485/setup_ai/v2.0.1/mac/mac-setup.sh -o /tmp/ai-mac-setup.sh && bash /tmp/ai-mac-setup.sh

ZIP 内のスクリプトを使いたい場合だけ:

DIR=$(find "$HOME/Downloads" "$HOME/Desktop" "$HOME/Documents" -maxdepth 4 -type d -name 'AI-Dev-Setup' 2>/dev/null | head -n1); if [ -z "$DIR" ]; then echo "AI-Dev-Setup フォルダが見つかりません"; else cd "$DIR" && xattr -dr com.apple.quarantine . && bash mac/mac-setup.sh; fi

コピーしました。ターミナルに貼り付けて Enter を押してください。

別の方法

  1. Start_Mac.command を右クリック
  2. 「開く」を選ぶ
  3. 確認画面でもう一度「開く」

Homebrew 導入時だけ、Mac のログインパスワードを聞かれます。

Windows の手順

  1. Start_Windows.bat をダブルクリック
  2. SmartScreen / Defender の警告が出たら「詳細情報」→「実行」
  3. WSL2 の確認（UAC）が出たら「はい」
Start_Windows.bat を開く

終わったら新しい PowerShell を開き、claude でログインしてください。

OS を自動判定できませんでした。Windows なら Start_Windows.bat、Mac なら上のターミナル手順を使ってください。
