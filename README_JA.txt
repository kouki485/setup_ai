============================================================
 AI 開発環境セットアップ
 （ダウンロード → 展開 → ダブルクリック）
============================================================

この ZIP を展開したフォルダの中で、使っている OS の
スタート用ファイルをダブルクリックしてください。

  Windows の場合:
    Start_Windows.bat

  Mac の場合:
    Start_Mac.command

------------------------------------------------------------
 Windows での注意
------------------------------------------------------------
・SmartScreen や Defender の警告が出たら
  「詳細情報」→「実行」を選んでください。
・WSL2 の導入時だけ UAC（管理者確認）が出ます。「はい」を選んでください。
・終わったら新しい PowerShell / ターミナルを開き、claude でログインします。

------------------------------------------------------------
 Mac での注意
------------------------------------------------------------
・初回だけ「開発元を確認できない」と出ることがあります。
  そのときはファイルを右クリック →「開く」→「開く」。
・Homebrew 導入時だけ Mac のログインパスワードを聞かれます。
・終わったら新しいターミナルを開き、claude でログインします。

------------------------------------------------------------
 入るもの
------------------------------------------------------------
・Claude Code / Claude Desktop
・Git / Node.js (LTS) / GitHub CLI (gh)
・Vercel CLI / Supabase CLI
・WSL2 (Ubuntu) … Windows のみ
・Homebrew / Xcode Command Line Tools … Mac のみ
・claude などをコマンド名だけで使えるよう PATH も設定します

------------------------------------------------------------
 うまくいかないとき
------------------------------------------------------------
デスクトップに ai-setup-log.txt が残ります。
このファイルを管理者に送ってください。
何度実行しても安全です（導入済みの項目はスキップされます）。
