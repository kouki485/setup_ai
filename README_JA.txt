============================================================
 AI 開発環境セットアップ
 （ダウンロード → 展開 → Start.html を開く）
============================================================

1. ZIP をフォルダごと展開する
2. 展開したフォルダ内の Start.html をダブルクリックする
3. 画面の案内に従ってセットアップする

------------------------------------------------------------
 Mac で Start_Mac.command がエラーになる場合
------------------------------------------------------------
ダウンロードした .command をダブルクリックすると、macOS の
セキュリティで「検証できません」と止まるとがあります（仕様）。

対処（どちらか）:
  A. Start.html を開き「コマンドをコピー」→ ターミナルに貼り付け
  B. Start_Mac.command を右クリック →「開く」→「開く」

------------------------------------------------------------
 Windows
------------------------------------------------------------
・Start.html を開くか、Start_Windows.bat をダブルクリック
・SmartScreen が出たら「詳細情報」→「実行」
・WSL2 の UAC が出たら「はい」

終わったら新しいターミナルで claude と入力してログインしてください。
